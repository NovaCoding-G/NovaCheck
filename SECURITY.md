# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security → Report a vulnerability** form (GitHub
private vulnerability reporting). If that form is not available yet, email
[novacodingg@gmail.com](mailto:novacodingg@gmail.com) privately. Include:

- affected NovaCheck version;
- reproduction steps or a minimal fixture;
- expected and actual behavior;
- potential impact.

Never include real credentials, private source code, or customer data.

## Scope

Security reports about secret leakage, command execution, path traversal,
malicious package resolution, SARIF output, and unsafe handling of scanned
repositories are in scope.
